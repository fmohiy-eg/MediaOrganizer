# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A headless media-library auditor. Scans Movies/TV shares, fingerprints files, reads stream specs, identifies titles, flags duplicates / quality variants / missing episodes / subtitle gaps, fetches subtitles, and safely quarantines files chosen for removal. Design spec: `Plan3.md`; sequenced implementation plans: `plans/`.

This is the **shareable/distributable** build (forked from a single-user QNAP setup). It runs in two shapes: **single-machine** (media on a local/external/mounted drive, everything in one place, `path_map: {}` — the documented default) or the original **NAS+PC split** (scan on the NAS, dashboard on a PC, `path_map` translating NAS↔SMB). Cross-platform. First-run setup is `python setup_wizard.py` (the `src/wizard.py` wizard). Almost everything that was hardcoded to one environment is now config-driven; see `config.example.yaml`.

## Commands

```bash
pip install -r requirements.txt
python setup_wizard.py                                # first-run wizard -> writes config.yaml
python -m pytest -q                                   # full suite (~272 tests)
python -m pytest tests/test_parsing.py -q             # one file
python -m pytest tests/web/test_inspect.py::test_format_duration -v   # one test
python cli_engine.py config.yaml                      # interactive CLI engine (7-task menu)
python run_dashboard.py config.yaml                   # web dashboard at http://localhost:8080
```

Operational runners (drive the real library; each takes `config.yaml`). NAS-side run on the NAS; PC-side on the laptop:
- `scan_live.py` (NAS) — observable **inventory** scan (catalog only, no byte reads) with live `[n/total]` progress.
- `read_nfo_ids.py` (NAS) — fill `metadata_id` from existing Jellyfin/Kodi `.nfo` files (no API calls).
- `prune_live.py` (NAS) — removal half of a full sync: delete catalog rows whose file no longer exists on disk. **NAS-only** (off-NAS, `/share/...` paths never resolve, so it would wipe the whole catalog); dry-run by default, `--apply` to commit. No network deps.
- `gaps_live.py` (PC) — fetch + cache each TVDB series' episode list (`metadata_cache.episode_map`) so the Missing-Episodes tab works offline.
- `match_live.py` (PC) — fallback TMDB/TVDB matching, deduped to one lookup per distinct title.
- `probe_dupes.py` (PC) — ffprobe over SMB for the `services.probe_targets` set (every duplicate-group file + every movie, **minus DVD `VIDEO_TS` `.vob` fragments**, which can't be probed standalone), storing `duration_ms`/resolution/codec/`audio_languages` (feeds the Duplicates runtime split + Arabic-audio). Resumable; ~0.6 files/s over SMB. The Admin **Probe** panel reuses `probe_targets` to show done/target/remaining + the unprobeable-file list.

`config.yaml` is gitignored (run `python setup_wizard.py`, or copy `config.example.yaml`). **API keys** layer in via `src/secrets.apply_secrets` (called at the end of `load_config`): precedence **process env > `.env` file (next to config.yaml) > config.yaml**; an empty env/.env value never clobbers a real yaml value. Ship `.env.example`. For a **NAS+PC split** there are two config files (NAS-local paths; PC SMB paths + `path_map`); **single-machine** uses one config with `path_map: {}`. Tests run fully offline. End-user guide: `RUNBOOK.md`.

## Deployment reality (this is non-obvious and shapes everything)

The app runs in **two places at once**:

- **Scanning + `.nfo` reading run ON the NAS** over SSH (local disk is ~1000× faster than SMB). The NAS has Python 3.12 at `/usr/local/bin/python3` but **no pip** (so `PyYAML` is vendored into the app dir) and **no ffprobe** (stream fields stay blank there). Code is staged to the NAS over the SMB `Public` share. The user runs the SSH commands themselves.
- **The dashboard runs on the PC** (web framework, internet, SMB write access, local `ffprobe`). The catalog stores **NAS paths** (`/share/TV Shows/...`); `config.path_map` translates these to SMB (`\\host\TV Shows\...`) for any file operation (`web.subtitle_fetch.to_local_path`). **`ffprobe`/VLC are now auto-detected cross-platform** (`src/toolpaths.resolve_ffprobe`/`resolve_player`): a configured `config.ffprobe.binary`/`config.player.binary` wins, else PATH lookup, else platform default install locations; `""` (the new default) means auto-detect. `launch_player` is cross-platform (`os.startfile`/`open`/`xdg-open`). On single-machine, `path_map` is empty so `to_local_path`/`to_nas_path` are passthroughs and the catalog stores local paths directly.

## Architecture

Two entry points sit on a **shared SQLite database** (`media_audit.db`) and a layer of **small, pure, independently-tested modules** under `src/`. Entry points and runners contain only wiring.

- **`cli_engine.py`** — interactive menu; `run_task(choice, config)` runs one task non-interactively (tests drive this).
- **`web_dashboard.py`** — `create_app(db_path, quarantine_path, os_api_key, path_map, ffprobe_binary, ..., player_binary, audio_flag) -> FastAPI` factory (self-contained tabbed Tailwind UI + JSON endpoints). `run_dashboard.py` serves it via uvicorn, resolves ffprobe/player via `toolpaths`, and injects config (incl. `audio_flag`).
- **`setup_wizard.py` / `src/wizard.py`** — first-run CLI wizard. `build_config_dict(answers)` is a pure (tested) answers→config function; `run_wizard(...)` does only prompting/validation/writing and is fully injectable (`input_fn`/`exists_fn`/`isfile_fn`/`which_fn`/`write_fn`/`platform_name`/`env`).
- **`src/secrets.py`** — `apply_secrets(config, env, dotenv_path, read_file_fn)` overlays API keys from env/`.env`. **`src/toolpaths.py`** — `resolve_ffprobe`/`resolve_player` cross-platform binary resolution.

Module pipeline, in data-flow order:
- **Ingest:** `scanner.discover` (walks shares; prunes `.trickplay` **and** NAS system dirs `.@__thumb`/`@Recycle`; classifies media/nfo/subtitle/artwork) → `hashing` + `probe` → `indexer.scan_and_index` orchestrates and upserts via `repository`. `scan_and_index(..., compute_hashes=False)` is **inventory mode** (no byte reads, no ffprobe) for the fast catalog pass.
- **Identify:** prefer `nfo.extract_ids` (reads IDs Jellyfin already resolved). `parsing.parse_path` derives identity from the path; `matcher` + `metadata_client` (TMDB bearer / TVDB login) are the API fallback; `metadata_repository` caches + sets `match_status`. **`matcher.decide_match` is conservative on purpose** (single candidate, or a unique year hit) but also accepts a **unique exact normalized-title** match — only for episodes (folder-derived series names are reliable) or when a year corroborates, so a junk no-year *movie* title (e.g. a "Specials"/"Music Videos" folder) can't silently exact-match an obscure film. This is what lets the Admin **Re-match** clear real shows like "Barry" that otherwise return many candidates.
- **Audit:** `src/audit/*` — one pure module per dimension (`quality`, `duplicates`, `release_protection`, `contamination`, `subtitles`, `gaps`).
- **Delete:** `src/quarantine/*` — `cascade.build_deletion_plan` (DB → plan) → `mover` moves into quarantine.
- **Present (`web_dashboard.py` tabs: Overview · Dupes·Same-length · Dupes·Diff-length · Mismatch Videos · Cleanup · Missing Episodes · Subtitles · Arabic Audio · Needs Review · Organize Folder · Admin):** `src/web/services.py` (DB → dashboard JSON: variant groups with `runtime_class` same/different/unknown split, legacy-duplicate cleanup, missing-episode diff via `audit.gaps`, subtitle deficits), `web/inspect.py` (on-demand ffprobe → runtime/embedded-subs/**container internal title** + different-versions verdict + `title_mismatch`), `web/subtitle_fetch.py` (OpenSubtitles download→unzip→UTF-8→rename→move), `web/subtitle_ingest.py` (collision-safe rename), `web/relocate.py` (Jellyfin path builder + move for the "Fix" flow), `web/organize.py` (point-at-a-folder TV importer: ffprobe embedded tags → TVDB identify → Jellyfin rename/move, preview-then-confirm). The dashboard also launches files in VLC (`launch_player`), serves the page with `Cache-Control: no-store`, and uses `gaps_live.py`'s cached `episode_map` + `probe_dupes.py`'s stored runtimes.

## Cross-cutting invariants (span files — preserve them)

- **Dependency injection for testability:** external effects are always injectable so the suite runs offline. `indexer` takes `probe_fn`; `metadata_client` takes `http_get`/`http_post`; `opensubtitles_client` takes `http`; `web_dashboard.create_app` takes `os_client`/`http_get`/`probe_fn`; ingestion takes `exists_fn`/`write_fn`. Tests pass fakes.
- **A "duplicate group" = same folder + same base name, different extension** (`Movie.mkv`/`Movie.mp4`/`Movie.avi`) — see `web.services._variant_key`. **Never group by `metadata_id`:** every episode of a show shares the series-level `tvdb:` id, and multi-part files (`CD1…CDn`) share one `movie.nfo`, so id-grouping produces catastrophic false "delete all but one" sets.
- **Before suggesting a delete, confirm it's actually a duplicate, not a different version.** `web.inspect.assess_versions` flags a group when runtimes differ (≥ `audit.duration_deviation_seconds`) or a filename carries an edition marker (Director's Cut/Extended — `parsing.parse_path` `edition`). The dashboard keeper label is "KEEP?", not "KEEP".
- **Cascade preserves sidecars still claimed by a surviving same-name copy.** Format variants share `Movie.nfo`/`Movie.eng.srt`/`Movie.trickplay`; deleting one copy must not remove sidecars the others use. `cascade.build_deletion_plan` only cascades a sidecar owned *exclusively* by the deleted file (and never folder-global assets — `quarantine.assets.is_global_asset`).
- **Dry-run by default for any destructive action.** `mover.execute_plan` moves only when `dry_run=False`; the dashboard execute endpoint requires `confirm=true`. "Delete" = move to a central quarantine (manual purge), never `unlink`.
- **Quarantine deletes MUST translate catalog paths through `path_map` before touching disk.** The catalog stores NAS paths (`/share/...`); on the PC those don't exist. `execute_plan(..., to_local=lambda p: to_local_path(p, path_map))` maps the source to its SMB path, and **raises `FileNotFoundError` if the (mapped) video is unreachable** so the caller (`delete_execute`/`cleanup_legacy_execute`) does NOT call `delete_media_by_path`. Regression that bit before: delete passed the raw `/share/...` path, `os.path.exists` was False, the move was silently skipped, yet the DB row was dropped — files looked "deleted" in the UI but were never moved (still on disk; quarantine never created). Relocate/Arabic already path-map; delete/cleanup must too.
- **The dashboard `esc()` helper must escape backslashes, not just quotes.** Row buttons embed the filepath in `onclick="fn('${esc(path)}')"`; a backslash in a JS string literal is an escape char, so an unescaped `\\host\share\…` path is corrupted before the handler runs (symptom: endpoint 404 → "From/To: undefined"). `esc = s => s.replace(/\\/g,'\\\\').replace(/'/g,"\\'")` — backslash pass first, then quotes.
- **Relocate/Arabic destinations must be stored NAS-style — keep the catalog uniformly `/share/...`.** `media_paths` in the PC config are **SMB** paths (`\\host\Movies\01-Ready`), so `_target`/`_arabic_dest` reverse-map the `pick_roots(media_paths)` root back to NAS via `subtitle_fetch.to_nas_path` (the inverse of `to_local_path`) **before** `build_target`/`arabic_target`. The repointed row is then NAS-style; the on-disk move still goes through `to_local_path(dest)` → SMB. **Don't** store the raw SMB dest — it mixes path styles and a future `scan_live.py` re-adds the `/share/...` form as a duplicate row. Resolved 2026-06-25 (was a known-open issue); the 194 pre-existing backslash rows were migrated by `migrate_path_style.py` (string-only rewrite, reversible, re-runnable; dry-run by default).
- **DB writes serialize through `database.db_write_lock`; connections use WAL.** Index lookups at scale need the indexes in the schema (`idx_sidecar_media`, etc.) — a correlated subquery without them hangs on 57k rows.
- **`metadata_id` is namespaced** `tmdb:<id>` / `tvdb:<id>`.
- **Two-tier duplicate rule:** `fast_hash` is a candidate only; byte-identity needs `full_hash`. Inventory scans store `""` for both — a hash/dedup-confirm pass is separate.
- **Parsing: folder context overrides filename.** Series/year from `Series (Year)`, season from `Season NN`/`Specials`. **Anchor on the `SxxExx`/`NxNN` token** for the episode title (titles contain ` - `). Validated against `tv.txt`/`movies.txt` (real path dumps) — re-run that check when changing the parser.
- **`os_hash` includes the filesize term** and needs files ≥64KB.
- **`probe_streams` must decode ffprobe output as UTF-8** (`encoding="utf-8", errors="replace"`) — Windows defaults to cp1252, which crashes on non-ASCII container metadata.
- **The Duplicates same/diff-length split** (`services._runtime_class`) needs `duration_ms` populated by `probe_dupes.py`; until a group is probed it is `unknown` and shown under "Diff length".
- **The Mismatch-Videos tab** (`services.mismatched_videos`) lists movie-library video files whose base name (case-insensitive, sans extension) ≠ their parent-folder name — multi-part `CDn`, scene-named files, stray episodes/samples. Scoped to the movies prefix via `_movies_prefix()`: in a NAS+PC split it's the `path_map` key mentioning "movie" (catalog is NAS-style); **single-machine (empty path_map) falls back to `pick_roots(media_paths)` mapped through `to_nas_path` (a no-op when path_map is empty)** so it matches the locally-stored catalog paths — without this fallback the tab silently goes empty single-machine. TV is a separate root, so episodes (never matching their `Season NN` folder) are excluded. Rows reuse the shared `openFix` relocate flow; `fixConfirm` resets `window.mismatchLoaded` so fixed files drop off.
- **The Organize-Folder tab** (`web/organize.py` + `/api/organize/scan|apply`) imports a loose folder of TV files into the library. By design (user choice) it derives show/season/episode from **embedded ffprobe tags only** (`extract_episode_tags` reads `show`/`season_number`/`episode_id`/`episode_sort` from format+stream tags, case-insensitive; format wins) — **not** the filename. **Fallback:** when those structured tags are absent it parses a composite **`title`** tag of the form `"<Show> SxxExx <Episode Title>"` / `"<Show> NxNN …"` (`_parse_composite_title`) — this is the common real case (HandBrake writes the whole thing into `title`), and it's still embedded metadata. `classify_sidecars` matches siblings on `base + "."` (NOT a bare prefix — `CD10` must not grab `CD100`'s sidecars). Files without usable tags are reported as `no_tags` and skipped (most plain downloads lack these tags — a filename fallback is the obvious future toggle if asked). Flow: `scan` walks the folder (`walk_fn`), probes each video (`probe_raw_json`, injected as `probe_json_fn`), identifies via TVDB (first search hit, per-scan cache, get_episodes for the ep title), builds the Jellyfin dest with `relocate.episode_target`, and classifies sidecars (`classify_sidecars`: same-base-name subtitles → move+rename via `subtitle_dest`; other sidecar/info files → quarantine; other video formats left alone). `apply` **recomputes** every dest server-side from the structured fields (never trusts client dest), moves via the shared `_relocate_or_http` (source folder path is already local so `to_local_path` is a no-op on it; dest is NAS→SMB), quarantines removals through `_quarantine_loose` (central quarantine, collision-safe, never unlink), and best-effort `upsert_media_file` indexes the moved episode so it shows immediately. **The UI offers a decision per file (checkbox) and a batch (Select all); `apply` receives only the selected items.** With **Clean up leftovers** on, after the moves it sweeps the folder's remaining immediate children (stray artwork/`.nfo`/`.trickplay` dirs) into quarantine and `rmdir`s the emptied folder — but **only if no video remains** (`scandir_fn`; a deselected/unidentified episode keeps the folder and its siblings intact). Preview-then-confirm; `apply` requires `confirm=true`. Destinations are NAS-style (TV root reverse-mapped via `to_nas_path`), consistent with the path-style invariant.
- **The Admin tab** (PC-only, no auth — single-user LAN app) groups maintenance: a **catalog-status** panel (`services.admin_status` cheap counts + DB mtime + build stamp), **OpenSubtitles quota** (`opensubtitles_client.user_info` → `/api/subtitles/quota`, live, needs an active session login), **DB backup** (`/api/admin/backup` via SQLite's `conn.backup()` — a consistent snapshot even while the probe writes; also auto-run before a sync) + **integrity check** (`PRAGMA integrity_check`), and **Sync deletions** — the PC-side removal sync (`web/sync.find_missing` parallel-stats every catalog path via `to_local_path` over SMB; `/api/admin/sync/scan` runs it in a background thread with a progress-polled `/status`, `/apply` backs up then bulk-deletes the missing rows). This is the dashboard-native alternative to NAS-side `prune_live.py`, so routine deletion-sync needs no SSH and no destructive whole-DB copy. It also has a **Quarantine browser** (`/api/admin/quarantine/scan` background-walks the central quarantine → total size + count + largest items; `/api/admin/quarantine/purge` confirm-gated `rmtree` — the one action that truly erases files) and **Enrichment jobs**: **Re-match** (`/api/admin/rematch/*`, in-process `_bg_run` job; looks up unmatched titles on TMDB/TVDB, one lookup per distinct title) and **Probe** (`/api/admin/probe/start|status|stop` launches `probe_dupes.py` as a detached process via injectable `spawn_probe_fn`; status reports done/target/remaining via `probe_targets` + a progress bar + the list of files that couldn't be probed — `running` is inferred from the probed count climbing, not just the in-memory handle, so a restart can't offer Start while a detached probe is mid-run). Background jobs share the `_bg_run(job, work)` helper (daemon thread → `job['result']`); `database.get_connection` sets `PRAGMA busy_timeout=5000` so the dashboard and the detached probe/sync (separate processes) don't error on write contention.
- **The audio-language flag tab** (`services.flagged_audio_movies(conn, languages, staging_subdir)`, formerly "Arabic Audio") flags movies whose `audio_languages` JSON intersects the configured `audio_flag.languages` (case-insensitive; tagged only, needs `probe_dupes.py`), and its **Move** (`/api/audioflag*`) reparents the video to `<movies_root>/<staging_subdir>/<folder>/` via `relocate.flagged_target` + the shared `relocate_file` (no-overwrite). Sidecars are left behind; the row is repointed (`update_media_path`). **Config-driven and off by default:** empty `audio_flag.languages` ⇒ the service returns empty and the frontend self-hides the tab (a tiny `/api/config` bootstrap sets the label + visibility). Set `languages: ["ara"]`, `label: "Arabic Audio"`, `staging_subdir: "02-ArabicReady"` to restore the original behavior. `/api/summary` returns `flagged_movies`/`flagged_label`.
- **The dashboard tab/panel toggle must hide only `section[data-panel]`, never bare `[data-panel]`.** The two Dupes tab *buttons* also carry `data-panel="duplicates"` (to map tab→section), so a bare `[data-panel]` selector in `showTab()` adds `hidden` to the buttons themselves whenever a non-duplicates tab is active — on the default Overview tab the Dupes tabs vanish on load and can never be reopened, making the app look like an old version while serving correct HTML (curl shows the buttons; the browser doesn't).
- **`has_english_audio` is tri-state** (`yes`/`no`/`unknown`); the subtitle rule never guesses on `unknown`. The `sidecar_assets.asset_type` CHECK must include `'subtitle'` or subtitle sidecars are silently dropped by `INSERT OR IGNORE`.
- **OpenSubtitles:** search works with the API key; download needs a user-login token held **in server memory only** (never written to config/disk); the `/download` response carries the daily quota (`remaining`/`reset_time`) which the UI surfaces.

## Conventions

- TDD throughout: every module has a matching `tests/` file; synthetic fixtures in `tests/conftest.py` (`write_binary`, `write_os_hash_file`) avoid real media. Mirror this when adding modules.
- All policy thresholds come from `config.yaml` merged over `config.DEFAULTS` — add new tunables there, never hardcode.
- Plan-driven: spec section in `Plan3.md` → numbered plan in `plans/` → implemented task-by-task with frequent commits on a feature branch merged (`--no-ff`) to `master`.
